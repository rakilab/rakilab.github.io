# プライバシーポリシー

あさよるログ（以下「本アプリ」）は、利用者の情報を次のとおり取り扱います。

## 1. 収集する情報

本アプリ自体は、利用者の個人情報や利用状況を収集・送信しません。サーバーを持たず、解析ツールや広告は使っていません。トラッキングもしません。

なお、iOSの設定で「Appデベロッパと共有」を許可している場合は、Appleを通じて、個人を特定しない形のクラッシュ情報が開発者に届くことがあります。

このページやヘルプなどのWebページは GitHub Pages で公開しており、閲覧したときのアクセスログは GitHub が取得することがあります（その扱いは GitHub のプライバシーポリシーによります）。

## 2. 端末に保存する情報

次の記録は、お使いの端末の中（と端末のバックアップ）にだけ保存されます。開発者を含め、外部に送信されることはありません。iCloud への同期もしません。

- 朝の体感、夜の調子、一言メモ
- 夜の推測の結果と、答え合わせをした日のヘルスケアの値（1日1件）
- 薬の名前と時刻、服薬の記録
- 通知の時刻などの設定

## 3. ヘルスケアのデータ

本アプリは、利用者が許可した場合に、ヘルスケアから睡眠、歩数、アクティブエネルギー、安静時心拍数、心拍変動（HRV）を読み取ります。書き込みはしません。

読み取った値は、夜の推測と画面の表示にだけ使います。広告、マーケティング、第三者への提供には使いません。連携しなくても、体感と調子の記録は使えます。

## 4. 服薬の記録

薬の名前と服薬の記録は、端末の中にだけ保存します。通知とウィジェットには薬の名前を出しません。

## 5. 通知

通知は、端末の中で予約するローカル通知だけです。通知のために外部と通信することはありません。

## 6. バックアップと削除

記録は端末のバックアップ（iCloud バックアップ、Mac へのバックアップ）に含まれます。機種変更のときに記録を引き継ぐためです。バックアップの扱いは Apple の方針によります。

本アプリを削除すると、端末の中の記録はすべて消えます（バックアップに残っている分を除きます）。

## 7. お問い合わせ

お問い合わせのメールでいただいたメールアドレスと内容は、返信のためだけに使い、第三者に渡しません。対応が終わったら削除します。

アプリの「問い合わせ」から作るメールの本文には、アプリとiOSのバージョンが自動で入ります。送信前に消すこともできます。

## 8. 改定

このポリシーを改定したときは、このページでお知らせします。

# 使い方

FX記録帳（以下「本アプリ」）は、FXの取引を記録して、成績を自動で集計するためのアプリです。記録したデータは端末の中だけに保存され、外部に送信されません。

本アプリは取引記録と集計のためのツールであり、投資助言や売買の推奨を行うものではありません。

- [基本の使い方](#basics)
- [CSVの出し方](#csv-export)
- [汎用CSVの列の割り当て方](#csv-mapping)
- [よくある質問](#faq)

## 基本の使い方 {#basics}

画面の下に「記録」「分析」「設定」の3つのタブがあります。

### トレードを手入力する
1. 「記録」タブの右上の「＋」をタップし、「手入力」を選びます
2. 必須の項目（通貨ペア、売買、数量、決済日時、損益）を入れます
3. 必要に応じて、エントリー日時、エントリー価格、決済価格、スワップ、手数料、タグ、メモ、ルール遵守、スクショ画像を入れます
4. 右上の「保存」をタップします

- 通貨ペアと数量は、前回の入力が初期値になります
- エントリー価格と決済価格の両方を入れると、pipsを自動で計算します
- 「ルール遵守」は「守った」「破った」「未評価」から選べます

### 記録を見る・直す
- 「記録」タブに、トレードが月ごとに並びます
- 行をタップすると詳細が開きます。右上の「編集」で直せます。詳細の画面から削除もできます
- 左上の絞り込みのボタンで、通貨ペア・タグ・期間で絞り込めます。絞り込み中は一覧の先頭に条件が出て、「解除」で元に戻せます

### CSVで取り込む
1. 「記録」タブの右上の「＋」をタップし、「CSV取り込み」を選びます
2. ファイルアプリが開くので、取り込むCSVを選びます
3. LION FXの約定履歴なら、そのまま「取り込みの確認」の画面が出ます。それ以外のCSVは、列の割り当ての画面が出ます（[汎用CSVの列の割り当て方](#csv-mapping)）
4. 「取り込みの確認」で件数を確かめ、「N件を取り込む」をタップします

- 既にある記録と同じとみられる行は「重複の可能性」として数え、ふだんは取り込みません。取り込みたいときは「重複も取り込む」をオンにします
- 「タグ（任意）」で選んだタグを、取り込むすべてのトレードに付けられます
- 読み取れない行は「エラーになった行」として表示し、取り込みません

### 成績を見る
- 「分析」タブで、合計損益、取引回数（勝敗の内訳）、勝率、PF（プロフィットファクター）、期待値、平均利益、平均損失、損益比を見られます
- 上の「期間」で、全期間・今週・今月・今年・任意の期間を選べます

### タグを使う
- 「設定」→「タグ管理」で、タグの作成、名前と色の変更、並べ替え、削除ができます
- 手入力の画面や取り込みの確認の画面で、トレードにタグを付けられます

## CSVの出し方 {#csv-export}

本アプリは業者の取引履歴のCSVを取り込めます。業者のサイトやアプリでCSVを保存し、iPhoneの「ファイル」アプリから選べる場所（「このiPhone内」やiCloud Driveなど）に置いてください。

業者の画面や手順は変わることがあります。うまくいかないときは、業者のヘルプもあわせてご確認ください。本アプリは、以下の業者と提携・関係していません。

### LION FX（ヒロセ通商）
LION FXでは、約定一覧をCSVでダウンロードできます。「LION WEB」と「HTML5版」のどちらからでも保存できます。

ダウンロードしたCSVは、上のとおり「ファイル」アプリから選べる場所に置いてから、本アプリの「CSV取り込み」で選んでください。

以下は2026年11月時点の手順です。画面や手順が変わることがあるため、詳しくは[LION FXの公式Q&A](https://faq.hirose-fx.co.jp/)をご確認ください。

#### LION WEB
1. [LION WEB](https://lionfx.hirose-fx.co.jp/WTChartWeb/index.html) にログインします
2. 画面上部のレイアウト変更ボタンから、「レイアウト2」に変更します
3. 画面下部の「約定一覧」タブを選びます
4. ダウンロードしたい期間を指定して、更新します
5. 更新ボタンの右の「CSVダウンロード」ボタンから、ダウンロードします

#### HTML5版
1. [HTML5版](https://lionfx.hirose-fx.co.jp/web2/lionfx/index.html) にログインします
2. 画面左のメニューから「約定一覧」を表示します
3. 約定一覧タブの「＋」アイコンで、ダウンロードしたい期間を指定して検索します
4. 検索後、「CSV出力」ボタンでダウンロードします

#### 取り込みについて
- 約定履歴のCSVは、本アプリが自動で判別します。列の割り当ては要りません
- 決済した取引を1件ずつ取り込みます。新規約定の行は取り込みません
- 数量は、Lot数を通貨ペアごとの1Lotの通貨数で換算します

### そのほかの業者
取引履歴（決済した取引の一覧）をCSVで保存できる業者なら、汎用の取り込みで読み込めます。次の「汎用CSVの列の割り当て方」をご覧ください。

## 汎用CSVの列の割り当て方 {#csv-mapping}

LION FX 以外のCSVを選ぶと、「CSV取り込み」の画面が出ます。上から順に設定し、右上の「次へ」をタップします。

1. **文字コード**: 「UTF-8」か「Shift_JIS」を選びます。下のプレビューで文字化けしていない方を選んでください
2. **1行目は見出し**: CSVの1行目が列の名前なら、オンにします
3. **列の割り当て**: 本アプリの項目ごとに、CSVのどの列を使うかを選びます。「例:」に、その列の先頭の値が出ます
   - 必須: 通貨ペア、売買、数量、決済日時、損益
   - 任意: エントリー日時、エントリー価格、決済価格、スワップ、手数料、メモ
4. **日付の形式**: CSVの日時の書き方を選びます。合わないときは「自由入力」で、例えば `yyyy/MM/dd HH:mm:ss` のように入れます（yyyy=年、MM=月、dd=日、HH=時、mm=分、ss=秒）。日時は日本時間（端末のタイムゾーン）として読みます
5. **このマッピングを保存**: 名前を付けて保存すると、次回は「保存したマッピング」から選ぶだけで済みます。保存したマッピングは「設定」→「取り込み設定」で名前の変更や削除ができます

### 割り当てのこつ
- **通貨ペア**: 「USD/JPY」「USDJPY」「USD_JPY」のような書き方を読めます
- **売買**: ポジションの方向（新規の売買）の列を選びます。「買」「買い」「買建」「buy」「long」「ロング」などと、「売」「売り」「売建」「sell」「short」「ショート」などを読めます
- **数量**: 通貨数（例: 10,000通貨なら 10000）で入っている列を選びます。Lot数の列を選ぶと、数量が通貨数と違う値になります
- **損益**: スワップと手数料を含まない売買損益の列を選びます。スワップと手数料の列があれば、それぞれに割り当ててください。合計の損益（決済損益）は本アプリが計算します
- 金額の「円」「¥」やカンマ、全角の数字は、そのまま読めます

## よくある質問 {#faq}

### 無料版では、どこまで取り込めますか？
無料版のCSV取り込みは、今日を含む直近30日分（取引日で数えます）の取引までです。それより前の行は「取り込みの確認」で「無料版の範囲外（取り込まない）」として数え、取り込みません。Pro版（買い切り）を購入すると、期間の制限なく取り込めます。

- 取引日は「設定」→「日の区切り」に従って数えます
- 「今日」は、端末の日付と、記録済みのトレードの最新の決済日時の、遅いほうで決めます
- 手入力には期間の制限はありません

### 機種変更したら、Pro版を買い直す必要がありますか？
いいえ。同じApple IDでサインインし、「設定」→「購入の復元」をタップしてください。Pro版の画面にも「購入の復元」があります。Pro版はファミリー共有に対応しています。

### 「数量の倍率」とは何ですか？
手入力の数量は「入力値 × 倍率」で入れます（例: 「250 ×1,000」＝250,000通貨）。倍率は ×1、×1,000、×10,000、×100,000 から選べます。

「設定」→「数量の倍率」で、通貨ペアごとに新しく記録するときの倍率を決められます。決めていない通貨ペアは、その通貨ペアで前回使った倍率（記録がなければ ×10,000）になります。

### 「日の区切り」とは何ですか？
1日をどこで区切るかの設定です。「設定」→「日の区切り」で選べます。

- **日本時間0時**: 日本時間の0時で日を区切ります
- **NYクローズ**: ニューヨーク時間の17時（日本時間で夏は6時、冬は7時）で日を区切ります

一覧の月の区切り、一覧の絞り込みと分析の期間、無料版の取り込みの範囲に使います。

# プライバシーポリシー

FX記録帳（以下「本アプリ」）は、利用者の情報を次のとおり取り扱います。

## 1. 収集する情報

本アプリ自体は、利用者の個人情報や利用状況を収集・送信しません。解析ツールや広告は使っていません。

なお、iOSの設定で「Appデベロッパと共有」を許可している場合は、Appleを通じて、個人を特定しない形のクラッシュ情報が開発者に届くことがあります。

このページやヘルプなどのWebページは GitHub Pages で公開しており、閲覧したときのアクセスログは GitHub が取得することがあります（その扱いは GitHub のプライバシーポリシーによります）。

## 2. 記録したデータの保存場所

トレードの記録、メモ、タグ、添付した画像、アプリの設定（取り込み設定、数量の倍率、日の区切りなど）は、お使いの端末の中（と端末のバックアップ）にだけ保存されます。開発者を含め、外部に送信されることはありません。添付画像の位置情報などのメタデータは保存しません。

## 3. 取り込むファイル

CSVファイルは端末の中で読み取ります。ファイルの内容が外部に送られることはありません。

## 4. 購入

Pro版の購入は Apple の App Store を通じて行われます。支払い情報を本アプリや開発者が受け取ることはありません。購入に関する情報の扱いは、Apple のプライバシーポリシーによります。

## 5. お問い合わせ

お問い合わせのメールでいただいたメールアドレスと内容は、返信のためだけに使い、第三者に渡しません。対応が終わったら削除します。

アプリの「問い合わせ」から作るメールの本文には、アプリとiOSのバージョンが自動で入ります。送信前に消すこともできます。

## 6. 改定

このポリシーを改定したときは、このページでお知らせします。
